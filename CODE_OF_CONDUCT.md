# Code of Conduct

## Educational Purpose Only

This project is provided strictly for educational and research purposes. This project is based on the original concept from [facebook-chat-api](https://github.com/Schmavery/facebook-chat-api) by Schmavery and serves as a TypeScript reimplementation for learning purposes.

By accessing or using this code, you agree to:

### Acceptable Use

- **Educational Research**: Study the code to understand web scraping and reverse engineering concepts
- **Academic Learning**: Use as reference material for programming courses or research
- **Personal Learning**: Explore TypeScript/Node.js development patterns

### Prohibited Use

- **Production Deployment**: Never use this code in production environments
- **Commercial Use**: Do not use for commercial purposes or profit
- **Account Abuse**: Do not use with real Facebook accounts
- **Privacy Violations**: Do not harvest or misuse others' personal data
- **ToS Violations**: Do not intentionally violate Facebook's Terms of Service
- **Malicious Activities**: Do not use for spam, harassment, or harmful activities

### Legal Compliance

Users must:
- Understand that this code violates Facebook's Terms of Service
- Accept full responsibility for any consequences of use
- Comply with all applicable laws and regulations
- Respect intellectual property rights
- Protect others' privacy and data

### Ethical Guidelines

- Use code knowledge responsibly
- Do not teach others to abuse social media platforms
- Consider the ethical implications of reverse engineering
- Respect platform policies even when studying their circumvention

### Disclaimer

The author:
- Provides this code for educational purposes only
- Assumes no responsibility for misuse
- Does not encourage ToS violations
- Is not liable for any damages or legal consequences

### Enforcement

Violations of this Code of Conduct may result in:
- Removal from project discussions
- Reporting to appropriate authorities if illegal activities are suspected
- No support or assistance with the project

By studying this code, you acknowledge understanding and agreement to these terms.
